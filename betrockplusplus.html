Betrock++ is a Beta 1.7.3-compatible Server and (eventually) Client written largely from scratch in C++.

It offers significantly improved performance, reduced memory usage, accurate terrain generation, mob behavior, gamerules, commands, a very capable addon system and much more!

For those interested in developing for the addon system, there exists the Addon Wiki, primarily focused on how to write an addon for the C ABI or how to write an addon binding for other languages, such as Rust.
